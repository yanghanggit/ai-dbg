# 图像生成模型（Replicate）

## 定位

Replicate 是项目的基础设施层：只负责把显式的生成规格转换为远端调用并落盘为图片资产，不参与游戏规则。调用方必须显式指定模型；库不提供默认模型，避免不同入口悄悄使用不同模型。

模型引用表由业务名映射到 Replicate 的 `model_ref`；模型支持的参数子集不同，生成规格中的尺寸、宽高比与模型专属参数由调用方负责选择。

## 显式模型

`TextToImageSpec` 与 `EditImageSpec` 都要求提供模型名。命令行入口同样要求 `--model`：文生图与图生图脚本在没有模型时直接报错，不会回退到任何默认值。

可用业务名包括 `ideogram-v3-turbo`、`stable-diffusion-3.5-large`、`flux-schnell`、`nano-banana`、`nano-banana-pro`；实际 `model_ref` 以代码中的模型引用表为准。

## Nano-Banana 支持尺寸

Gemini 2.5 Flash Image（`nano-banana`）支持以下宽高比与对应分辨率：

| 宽高比 | 分辨率（像素） | Token 消耗 | 适用场景 |
| ------ | -------------- | ---------- | -------- |
| 1:1 | 1024 x 1024 | 1290 | 正方形，社交媒体、头像、图标 |
| 2:3 | 832 x 1248 | 1290 | 竖屏，手机壁纸、竖版海报 |
| 3:2 | 1248 x 832 | 1290 | 横屏，传统摄影比例 |
| 3:4 | 864 x 1184 | 1290 | 竖屏，海报、宣传册 |
| 4:3 | 1184 x 864 | 1290 | 横屏，传统显示器比例 |
| 4:5 | 896 x 1152 | 1290 | 竖屏，Instagram 帖子 |
| 5:4 | 1152 x 896 | 1290 | 横屏，经典显示器比例 |
| 9:16 | 768 x 1344 | 1290 | 竖屏，手机全屏、Stories、短视频 |
| 16:9 | 1344 x 768 | 1290 | 横屏，宽屏视频、桌面壁纸 |
| 21:9 | 1536 x 672 | 1290 | 超宽屏，电影比例、超宽显示器 |

所有尺寸的 Token 消耗相同；默认分辨率等级为 1K，图片格式为 PNG 并自动添加 SynthID 水印。未指定宽高比时生成 1:1；优先使用模型原生支持的宽高比。

## 尺寸推导

文生图规格允许只给宽高；生成前会按宽高比选择最接近的受支持比例，非法尺寸回退到 1:1。图生图编辑直接使用调用方给出的 `aspect_ratio`，并支持 `match_input_image`。
