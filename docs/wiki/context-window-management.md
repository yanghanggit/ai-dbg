# 上下文窗口管理（Context Window Management）

## 意图

角色与舞台的 agent 记忆随回合单调累积，上行 prompt 持续膨胀，最终逼近模型上下文上限。当前保留两类基础能力：上下文占比信号与压缩原语；自动触发策略待 SRPG 规则落地后重新接入 pipeline。

## 上下文占比

模型响应后，token 用量占模型上下文窗口的比例写入该 agent 的记忆，并随 AI 回复消息一起同步。占比只是「这个 agent 有多满」的信号，不承载策略；读取方据此决定是否压缩。

## 压缩原语

压缩把首条 system prompt 之外的消息替换成一条摘要，保留显式标记为压缩保留的消息，并把占比归零。当前它是手动调用的记忆操作，没有自动定时器；何时触发、阈值多少属于玩法规则，待规则层定义。

压缩只保留首条 system prompt 与显式保留项。绝大多数事实型记录（胜负、阵亡等）只属叙事，允许被摘要吞掉——它们的权威载体是组件，记忆只负责让人记得大概发生过什么。

## 作用域

压缩是记忆层的操作，不改变 ECS 组件，也不进入游戏快照；ECS 与记忆是平级系统，各自管理自己的状态。自动触发系统缺失期间，需要时由调用方显式压缩。
