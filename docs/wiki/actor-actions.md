# 角色行为（Actor Actions）

## 结论

行为是计划的下半场。计划用工具往角色身上挂一个动作，三个行为 system 各自消费自己的动作：说话与等待把一句话广播给同一处的在场者，移动把角色挪到战场上的相邻一格。

一个动作只做一件事，动作只活一次 pass，收尾统一清除。

## 说话与等待都要说出口

说话广播的是「他说了什么」，等待广播的是「他什么也没做」。后者不是多余：「什么都没发生」和「没人在」是两件事，缺了它，沉默就无法与缺席区分。

广播范围取决于角色站在哪儿：据点里发给同一处的人与据点本身，站在空地上则按一格距离扩散——空地上没有「在场者」，只有远近。

说话者自己不收自己的广播，否则他会把自己刚说的话当成别人说的。

## 移动以战场格为单位

舞台树只有根带网格，所以「位置」只有一种含义：战场上的某一格。据点占据一格，人要么在据点里（坐标即据点的格），要么站在空地上（自己的坐标）。

因此移动只有两个结果：目标格上有据点就走进去，摘下自己的坐标；目标格是空地就站上去，写下坐标。目标必须相邻——越界或隔空跳都不执行，角色留在原地。

一格一物是舞台的规则，不是人的：同一格的据点只有一个，站在格上的人可以不止一个。

## 一次移动说给三处听

离开时旧处的人看见他走，到达后新处的人看见他来，他自己则记住这条路线的两端。第三句不能省：别人听到的「他来了」是旁观视角，回答不了「我从哪儿来」，缺了它，角色记忆里就没有自己的移动史。

这三句由一个专门的 mixin 负责，调用顺序即语义：先发离开、再改组件、最后发到达。顺序反了，旧处会听见「他来了」。

## 边界

行为只改位置与记忆，不改外观与环境——那些是描述刷新的职责。移动按相邻格校验，站在空地上的判定依赖角色自己的坐标，所以行为 system 必须排在计划之后。
