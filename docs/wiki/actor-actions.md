# 角色行为（Actor Actions）

## 两层地图，两套动词

世界有两层，位置的含义不同，因此动词也不同。

战役层是一张网格地图：一格要么是空地，要么是一个据点，人站在格上。据点层是据点内部的一棵树（城池、城区、建筑），人在节点上，没有坐标。

一个据点对外只是一个节点。无论在里面走到多深，对外它就是占一格的那一处。

判据只有两条：

- 地图是坐标系，不是场所。所以「在场者」只存在于据点层，也只在那里能说话。
- 站在同一张图上不等于站在同一处。所以地图上的移动与告知都只与自己、与地图有关。

## 动词表

| 动词 | 只在哪一层成立 | 结果 |
| --- | --- | --- |
| 战场移动 | 地图 | 走到相邻一格，只改坐标；可以停在据点格上（兵临城下） |
| 进城 | 地图 | 从据点所在的那一格进去，落到据点根，摘掉自己的坐标 |
| 出城 | 据点 | 回到战场上据点所在的那一格，无论在里面多深 |
| 城内移动 | 据点 | 走到子区域或父区域；父区域是战场时不算——那是出城 |
| 说话 | 据点 | 广播给同一区域的人与区域本身 |
| 等待 | 两层都可用 | 据点里广播「没动」；地图上什么都不发生 |

把「移动」拆成四个动词，是为了每个动作的前置条件都能一句话说清：在不在这一层、目标是否相邻、脚下是不是那个据点。合成一个动词时，「走到据点格」必然被解释成进城，兵临城下就表达不出来。

每个动词由一个 system 独占，`filter` 顺带做层级校验：层级不符的动作不会生效，也不会报错——它只是不属于这里。

## 位置的互斥表示

在据点里：所在舞台是那个区域节点，没有坐标。在地图上：所在舞台是全局舞台，坐标是自己的格子。没有第三种状态。

出城的落点不需要额外数据：就是据点根所在的格。进城的落点也不需要：永远是据点根。这条对称来自「据点对外只是一个节点」。

## 一次位置变化说给三处听

离开时旧处的人看见他走，到达后新处的人看见他来，他自己记住这条路线的两端。第三句不能省：别人听到的「他来了」是旁观视角，回答不了「我从哪儿来」。

投递对象由位置类型决定：

- 据点里的位置 → 该区域的在场者与区域本身；
- 地图上的位置 → 只写给地图自己。

后半条是「地图不是场所」的直接后果：在图上走动，同图上的人不该被当成旁观者叫醒，只有地图记下这次移动。

调用顺序即语义：先发离开、再改组件、最后发到达。顺序反了，旧处会听见「他来了」。

## 边界

行为只改位置与记忆，不改外观与环境——那些是描述刷新的职责。它挡在计划之后：计划挂动作，行为消费动作。
